# Images

## Aeltrix team image

Place your real team image at:

    assets/images/aeltrix-team.png

The About page loads this file automatically through `site-config.js`
(`assets.teamImage`). If the file is missing, the About page displays
a stylish placeholder with the Aeltrix wordmark — nothing breaks.

Recommended: square or 4:5 aspect ratio, at least 1200px on the long side,
under 400 KB, optimized as PNG or WebP.

Do NOT add AI-generated people here and pass them off as the real team.
If you do not want to show a photo, keep the placeholder or supply an
abstract logo/graphic instead.
